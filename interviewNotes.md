## Word Finder
-> "we have as many questions as time will allow today, and we'll just take them one at a time."

Your task is to write a function that, given a list of words and a string, finds and returns the word in the list that's inside the string.

let's go through some examples here. We have at most 1 matching word

* All letters are lowercase and the strings contain only letters.
* The inputs won't be empty or null.
* Empty string is an acceptable output value for the non-matching cases. Some languages won't allow nulls as outputs.
* You can treat the number of possible characters as constant for the purposes of complexity analysis.
* If the candidate mentions the length of the input string, tell them it's bounded by some constant times S (so something like 2S or 3S).

-> Complexity analysis, using W where W is the number of words and S where S is the size of the string 



## Grid Search

Given a grid and a word, write a function that returns the location of the word in the grid as a list of coordinates. If there are multiple matches, return any one.

* The word is guaranteed to be in the grid.
* The collection of coordinates must be in order of the characters of the word.
